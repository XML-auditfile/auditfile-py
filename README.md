# auditfile-py

Streaming reader for Dutch tax audit files (XAF and related), following
[auditfile-spec](https://github.com/XML-auditfile/auditfile-spec). The Python counterpart of
[auditfile-dotnet](https://github.com/XML-auditfile/auditfile-dotnet), with the same API in Python style.

> Status: draft (0.x).
> Not affiliated with the Belastingdienst, SRA or any software vendor.

```python
from xml_auditfile import Auditfile, AuditfileSource, MemorySink

sink = MemorySink()
source = AuditfileSource.from_factory(lambda: open("administratie.xaf", "rb"), "administratie.xaf")
report = Auditfile.read(source, sink)

for diagnostic in report.diagnostics:
    print(diagnostic)

for line in sink.rows("tr_line"):
    print(line["acc_id"], line["amnt"], line["amnt_tp"])
```

No dependencies: XML parsing uses the standard library's expat parser, XSD validation is built in.

## What it does

- **Determines the version**: forced in code, official namespace or alias from the registry, optionally
  derived from the namespace (`use_resolver`). Anything else stops with a clear diagnostic.
- **Reads in two phases**: scan (validate against the built-in XSD, count rows per table) and load
  (stream rows in batches to a sink). Verified mode loads only a valid file.
- **Turns every repeating element into a table** following the manifest generated by auditfile-spec.
  Rows know their id, parent, position and source part; values are typed.
- **Checks** required and expected tables, keys, references and the XAF business rules
  (balanced transactions, header counts and totals).
- **Reads split audit files** (`audit.xaf`, `audit-2.xaf`, ...) as one file; you pass the parts in order.
- **Reports** everything as diagnostics with stable codes, in Dutch or English.

## Entry points

| Call | Use |
| ---- | --- |
| `Auditfile.read(source, sink, options)` | Read into a sink: `MemorySink` or your own sink |
| `Auditfile.validate(source, options)` | Validate completely without storing anything |
| `Auditfile.scan(source, options)` | Version, XSD validation and row counts only |
| `Auditfile.open(source, options).read_rows()` | Stream rows yourself |
| `AuditfileVersion.Financial.V3_2` | Manifest, XSD, definitions, dialects and views of a version |
| `schema.to_json()` / `AuditfileSchema.from_json()` | Store and restore the schema of an import |

Sources: the reader never opens files; you supply binary streams (anything with `read(n)` returning bytes) or bytes.

| Call | Use |
| ---- | --- |
| `AuditfileSource.from_factory(open, name)` | Fresh stream per call: can be read twice (scan, then load) |
| `AuditfileSource.from_factories((name, open), ...)` | Same, for the parts of a split audit file |
| `AuditfileSource.from_stream(stream, name)` | Read once; validation then happens during loading. The stream is not closed |
| `AuditfileSource.from_streams((name, stream), ...)` | Same, for the parts of a split audit file |

Options are a frozen dataclass: `ReadOptions(version=..., mode=ReadMode.UNVERIFIED, use_resolver=..., xsd=...,
apply_dialects=..., batch_size=..., language=TextLanguage.ENGLISH, max_diagnostics=..., max_depth=..., on_progress=...)`.

A sink is any object with `begin(context)`, `write(table, rows)`, `complete(report)` and `abort(report)` (the `Sink`
protocol). Set `capabilities = SinkCapabilities.NEEDS_ROW_COUNTS` to get row counts before the first row.

## Values

| Column type | Python value |
| ----------- | ------------ |
| `string` | `str` |
| `decimal` | `decimal.Decimal`, exact with the scale as written; totals are added without rounding |
| `integer` | `int`, within the range of a 64-bit integer |
| `date` | `datetime.date`; a time zone in the file is ignored |
| `datetime` | `datetime.datetime`, aware when the file gives a time zone |
| `time` | `datetime.time` |
| `boolean` | `bool` |

## Security

The reader is built for files from untrusted sources:

- DTDs are refused, so no entity can be declared or expanded and nothing external is loaded (XXE, billion laughs).
- XSD imports resolve only to the definitions embedded in the package; never to disk or network.
- Nesting deeper than `max_depth` (64) stops reading; the root element must appear within the first megabyte.
- Memory does not grow with the file: only open elements, key values and unresolved references
  (capped per reference) are kept, and diagnostics are capped at `max_diagnostics`.
- Text streams are refused (their encoding is unknown); a stream you pass with `from_stream` is never closed.

## XSD validation

Validation uses a streaming validator for the XSD subset that auditfile-spec uses: global and local elements,
sequences with occurrence bounds, attributes, simple types with facets (enumeration, pattern, length, digits, ranges,
white space) and `key`/`keyref`/`unique`. Every XSD of the registry compiles; a custom XSD (`xsd` option) that uses
anything else (such as `xs:choice` or `xs:any`) is refused with `XsdError` when it is compiled, never validated halfway.
Like the .NET reader, identity constraints follow XPath 1.0: an unprefixed step selects elements without namespace.

## Layout

| Path | Contents |
| ---- | -------- |
| `src/xml_auditfile/` | The reader; `memory.py` holds `MemorySink`, `xsd/` the XSD validator |
| `tests/` | Tests (pytest), using the official XAF 3.2 test file from auditfile-spec |
| `samples/read_to_memory.py` | Read a file and print tables, a row with definitions, views and diagnostics |
| `samples/validate.py` | Validate a file; exit code 0 when valid |
| `spec.lock.json` | The pinned auditfile-spec release |
| `tools/` | `fetch-spec.ps1` (fetches the pinned spec into `spec/`) and `embed_spec.py` |

## Definitions

Everything in `generated/` of a pinned auditfile-spec release is embedded in the package as `xml_auditfile/_spec/`.
The spec is not committed: `spec.lock.json` pins a commit, `tools/fetch-spec.ps1` fetches exactly that commit into
`spec/` (git-ignored), and `tools/embed_spec.py` copies it into the package before testing and building.

```
pwsh tools/fetch-spec.ps1        # after cloning and whenever spec.lock.json changes
python tools/embed_spec.py
pip install -e ".[test]"
pytest
```

To use a local spec checkout instead: `SPEC_ROOT=../auditfile-spec python tools/embed_spec.py`.
